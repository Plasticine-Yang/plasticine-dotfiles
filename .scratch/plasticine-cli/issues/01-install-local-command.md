# 01: 发布并安装 plasticine 本地命令

Status: done

按 [统一规格](../spec.md) 建立稳定启动入口和版本化发布包，复用现有选装流程。

## Acceptance Criteria

- [ ] 一行安装建立本地命令，即使未选 shell 或空选择也可用。
- [ ] 支持交互选装、现有自动化参数、--help 和 --version，保持参数与退出码。
- [ ] 本地运行使用当前发布版元数据，不链接开发安装器，不自动更新自身。
- [ ] 发布包包含 CLI、安装器、自更新模块和版本元数据，并纳入现有 Release 构建验证。
- [ ] PATH 缺失时提供可直接执行的绝对路径与配置指引。
- [ ] 保留工具选择、取消、归属和冲突保护；重复初始化不会覆盖非受管同名命令。
- [ ] 隔离集成测试覆盖版本选择、参数传递、交互、PATH 与重复安装行为。
- [ ] 文档说明日常选装入口及前置安装的作用范围。
- [ ] 实现和相关验证完成后转为 done。

## Comments

与自更新任务共享发布包接口；本票完成不能仅以占位 self-update 模块代替整份规格的完成。
