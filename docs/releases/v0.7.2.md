# v0.7.2 发布记录

修复 Windows 真实安装路径上的两个缺陷（v0.7.0 起存在，v0.7.1 只修掉了第一个）：

1. `chezmoi_2.72.1_windows_amd64.zip` 的真实顶层成员是
   `LICENSE / README.md / completions / chezmoi.exe`，校验只允许 `chezmoi.exe`
   导致首次安装被拒；
2. 选中任意会准备工具的 Feature（lazygit/fnm/uv/rust/neovim/herdr/powershell）时
   `04_prepare_selected_tools` 模板渲染出 `@('a','b',)` 尾逗号数组，
   Windows PowerShell 5.1 解析失败，apply 直接退出。

## 新增回归

- `tests/windows/render.ps1`：用钉住的 chezmoi 对全部 19 个 `.ps1.tmpl`
  按三组 tools 渲染（41 份脚本），再用 PowerShell 解析，模板语法错误在套件内直接失败；
- CI 的 windows job 增加「安装钉住的 chezmoi（SHA-256 校验）」步骤，并通过
  `PLASTICINE_TEST_CHEZMOI_BIN` 提供给 render 套件（`check.ps1` 会隔离 PATH）。

## 发布版安装器 smoke（Windows PowerShell 5.1，一次性 HOME）

用 `D:\plasticine\install.ps1`（v0.7.2）与本地载荷目录执行：

```
install.ps1 -Yes -GitConfig -Npmrc -Lazygit -Fnm -Uv
```

- exit 0，25.2s；恢复 released source `aa1bd9e4…`；
- 真实安装 `lazygit 0.65.1`、`fnm 1.39.0`、`uv/uvx 0.13.8`；
- 生成 `~/.gitconfig` 与 owner-only 的 `~/.npmrc`；
- 临时 HOME 已清理，未触碰真实用户目录与 HKCU。

v0.7.1 已发布但含上面第 2 个缺陷，不再推荐；v0.7.0 含第 1 个缺陷。
