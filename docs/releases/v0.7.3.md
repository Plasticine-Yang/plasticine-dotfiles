# v0.7.3 发布记录

修复 PowerShell profile 片段的“交互式”判定：herdr 给每个 pane 的启动命令是
`powershell.exe -NoExit -Command "..."`（prompt 集成），旧逻辑只要看到
`-Command` 就当成脚本调用，跳过 `lg` 别名与 fnm 激活，表现为 herdr 里
`lg` 不存在而普通终端正常。`lazygit` 本身一直可用（在 PATH 上）。

## 判定规则

- `-NoExit` 存在 → 交互式（herdr、带 prompt 集成的宿主）
- `-File` / `-Command` / `-EncodedCommand` 且没有 `-NoExit` → 非交互（脚本宿主）
- `-NonInteractive` 始终优先

## 验证

- `powershell` 套件新增 3 个真实子进程回归：`-NoExit -Command` 必须有 `lg`
  别名，`-Command` 与 `-NonInteractive -Command` 必须没有；全量 14/14 通过
- 发布版 source bundle（`39339c5`）里的 `shared.ps1` 在 `-NoExit -Command`
  子进程里 dot-source 后 `Get-Alias lg` 命中（exit 0）
- Release 6 个附件下载后逐项复算 `SHA256SUMS` 一致

## 升级方式

重新运行安装器（会更新 `~/.plasticine/powershell/shared.ps1`），然后开新的
herdr pane；未升级前可在 pane 里临时 `Set-Alias lg lazygit`，或直接输入
`lazygit`。
