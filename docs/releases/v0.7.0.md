## 安装器 smoke（发布版，Windows PowerShell 5.1）

在一次性 HOME（`USERPROFILE`/`APPDATA`/`LOCALAPPDATA`/`TEMP`/`GIT_CONFIG_GLOBAL`
全部指向 fixture）里运行发布版 `install.ps1 -Yes -GitConfig -Npmrc`：

- 首次：退出码 0，使用 `PLASTICINE_RELEASE_ASSET_DIR` 恢复 release source bundle
  （`26b42c0`），生成 `~/.gitconfig` 与 `~/.npmrc`（owner-only DACL），
  chezmoi 配置固定 `[interpreters.ps1] command = "powershell"`；
- 二次：退出码 0，走维护路线并复用 source，apply 报告已收敛，不重写字节、
  不新增备份；
- 全程未安装 `pwsh`，未触碰真实用户目录与 HKCU。

POSIX 安装器 smoke 由 Release workflow 内的 `scripts/verify-release.sh` 在
Ubuntu 上执行（临时 HOME 运行 `install.sh`），随 Release run 一起通过。
