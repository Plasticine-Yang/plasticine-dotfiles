# Persist a Workstation Scope

Each Workstation will persist a simple exclusion set selecting which Components from the one Release-defined Desired State remain inactive; every other Component is enabled, including Components added by future Releases. Plain Plan and Apply reuse that Scope, one-run Component filters cannot expand it, and dependencies are resolved separately from personal configuration Components; a company Workstation can therefore require Git as software without allowing `git-config` or `github-ssh` to touch company-owned configuration. After blockers and authorization pass, Apply commits a changed Scope before Component effects and retains it through partial failure; excluding an already managed Component suspends it without deleting content or ownership, allowing later reactivation.
