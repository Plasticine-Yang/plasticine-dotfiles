# Adopt all Conflicts in the current Plan

The single `--adopt` option authorizes resolution of every adoptable Conflict in the filtered Plan after a unique backup; an unmanaged or continuing Managed Path enters or retains ownership, while Retirement deletes the backed-up drift and releases ownership. Plan displays the complete set before Apply, and Component filtering is the only way to narrow it. Non-interactive adoption also requires `--yes`, System Changes remain separately authorized, and Secret Reference targets can never enter adoption, avoiding a per-path selection DSL.
