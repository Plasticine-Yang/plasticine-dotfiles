# Limit CLI network egress and forbid telemetry

Bootstrap may access GitHub Releases, plasticine's own Apply HTTP client may access only Tool Lock artifact URLs, and Doctor may run bounded Release and enabled GitHub SSH diagnostics. Explicitly authorized System Changes may let `apt` or Apple's installer use their configured system sources, and later Tool-managed ecosystems retain their own network behavior. Plasticine performs no background update check, analytics, telemetry, or crash upload; its direct calls have explicit timeouts and standard proxy behavior.
