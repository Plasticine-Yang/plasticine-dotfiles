# Hand off installation to the candidate CLI

The POSIX Bootstrap will stop after platform detection, download, SHA-256 verification, chmod, and execution of a temporary candidate binary. A hidden candidate entrypoint then owns the exclusive lock, state compatibility check, atomic self-installation, option forwarding, and first Apply, keeping version, locking, and Reconciliation rules in the testable Go Module rather than duplicated shell. Compatibility or installation failure preserves the existing CLI; after atomic replacement succeeds, the candidate remains installed even when first Apply is denied, partial, or failed so a later run can resume from observed state. If the target path already contains an executable that cannot identify itself as a compatible plasticine CLI, installation refuses to overwrite it.
